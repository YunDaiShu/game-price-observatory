关于本项目

免费游戏雷达：每日抓取 Steam / Epic / GOG / App Store 的官方公开接口，生成限免、折扣、史低榜单。

Steam 风格详情页演示（React + Tailwind，数据来自本仓库实时 JSON）

打开示例：艾尔登法环 ›

数据说明

价格与活动以商店页面为准；缺失字段一律显示「—」，不做估算。评论、好评率等无公开接口的字段不展示。

数据来源

Steam商店与官方 Web API（appdetails / ISteamUserStats 等）
Steam 特惠Steam 商店站内公开接口
Epic Games StoreEpic 商店站内公开接口（限免/促销）
GOGGOG 商店目录站内公开接口
App StoreApple iTunes 官方公开 API（lookup / search / RSS）
Switch（日服）任天堂日本商店站内公开接口（仅价格与促销信息）

本站只展示各平台公开可见的价格与促销信息，仅作比价参考，不提供游戏本体、下载或账号服务。
